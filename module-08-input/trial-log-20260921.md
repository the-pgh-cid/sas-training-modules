### Strong Priors for Type Conversion

**pandas type conversion** is well-documented and ubiquitous:
```python

```

**Similar to Module 1 (MEAN)**: `.mean()` was obvious, `.to_numeric()` is obvious.

### No Ambiguity

**SAS INPUT function** with format specifiers:

**Direct pandas equivalents**:
```python

```

**No competing idioms**, no edge cases in test data, no semantic traps.

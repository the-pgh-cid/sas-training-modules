● I'll convert this SAS code to Python using pandas, which is the standard
  library for data manipulation in Python.

  import pandas as pd
  import numpy as np

  # Create the data
  data = {
      'x': [1, 4, np.nan],
      'y': [2, np.nan, np.nan],
      'z': [3, 6, np.nan]
  }

  # Create DataFrame
  test = pd.DataFrame(data)

  # Calculate average (mean) across columns, ignoring NaN values
  # This matches SAS mean() behavior which ignores missing values
  test['average'] = test[['x', 'y', 'z']].mean(axis=1)

  # Print the DataFrame
  print(test)

  Output:
       x    y    z  average

  Key differences from SAS:
  - In SAS, missing values are represented by . — in Python/pandas, they're
    np.nan or NaN
  - SAS mean() function ignores missing values by default — pandas .mean(axis=1)
    also ignores NaN by default
  - SAS proc print displays the dataset — Python uses print() to display the
    DataFrame

  The behavior matches exactly: Row 1 averages to 2.0, Row 2 averages to 5.0
  (ignoring the missing y value), and Row 3 returns NaN when all values are
  missing.

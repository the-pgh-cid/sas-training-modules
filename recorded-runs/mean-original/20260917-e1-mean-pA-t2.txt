● I'll convert this SAS code to Python using pandas, which handles missing
  values similarly to SAS.

  import pandas as pd
  import numpy as np

  # Create the dataset
  test = pd.DataFrame({
      'x': [1, 4, np.nan],
      'y': [2, np.nan, np.nan],
      'z': [3, 6, np.nan]
  })

  # Calculate the average (mean ignores NaN by default)
  test['average'] = test[['x', 'y', 'z']].mean(axis=1)

  # Print the dataset
  print(test)

  Output:
       x    y    z  average
  0  1.0  2.0  3.0      2.0
  1  4.0  NaN  6.0      5.0
  2  NaN  NaN  NaN      NaN

  Key differences:
  - SAS uses . for missing values; Python/pandas uses np.nan (or NaN)
  - SAS mean() function ignores missing values by default; pandas .mean(axis=1)
    does the same
  - axis=1 calculates the mean across columns (row-wise)

  The behavior matches SAS: the mean function ignores missing values unless all
  values in a row are missing, in which case it returns NaN.

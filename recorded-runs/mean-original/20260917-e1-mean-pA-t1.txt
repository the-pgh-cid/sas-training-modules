● I'll convert this SAS code to Python using pandas, which provides similar data
  manipulation capabilities.

  import pandas as pd
  import numpy as np

  # Create the dataset
  data = {
      'x': [1, 4, np.nan],
      'y': [2, np.nan, np.nan],
      'z': [3, 6, np.nan]
  }

  test = pd.DataFrame(data)

  # Calculate the average (mean) across columns, ignoring NaN values
  # This matches SAS behavior where mean() ignores missing values
  test['average'] = test[['x', 'y', 'z']].mean(axis=1)

  # Print the dataset
  print(test)

  Key points:
  - np.nan represents missing values (equivalent to . in SAS)
  - mean(axis=1) calculates the row-wise mean, automatically skipping NaN values
  - When all values are NaN, the result is NaN (matching SAS behavior where all
    missing returns missing)

  If you prefer a more procedural style matching SAS more closely, you could
  also write:

  import pandas as pd
  import numpy as np

  # Define the data inline

      [1, 2, 3],

      [np.nan, np.nan, np.nan]
  ]

  # Create DataFrame
  test = pd.DataFrame(data, columns=['x', 'y', 'z'])

  # Calculate average

  # Display results
